# Implementation Plan: NuGet Package Deployment

**Branch**: `011-nuget-packaging` | **Date**: 2026-04-20 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/011-nuget-packaging/spec.md`

## Summary

Publish all 12 TLio library projects as NuGet packages to NuGet.org. Preview packages (`0.1.0-preview.{N}`) are published automatically on every push to `main`. Stable releases (`X.Y.Z`) are published when a `vX.Y.Z` tag is pushed. Implementation requires: extending `Directory.Build.props` with shared NuGet metadata, enabling `IsPackable=true` on each library project, and creating two GitHub Actions workflows (`ci.yml` for testing, `publish.yml` for publishing).

## Technical Context

**Language/Version**: C# / .NET 10; YAML (GitHub Actions workflows)
**Primary Dependencies**: MSBuild SDK, GitHub Actions, NuGet.org API
**Storage**: N/A
**Testing**: NUnit (existing); no new tests required for CI/CD infrastructure
**Target Platform**: NuGet.org public package registry
**Project Type**: CI/CD pipeline + NuGet package metadata
**Performance Goals**: All 12 packages available on NuGet.org within 10 minutes of trigger
**Constraints**: All 12 packages share the same version per run; test and sample projects must never be packaged
**Scale/Scope**: 12 packages, 2 pipeline triggers (main push → preview, tag → release)
