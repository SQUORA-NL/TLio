## Highlights

### `resolve` joins through an index
`resolve` scanned its reference collection linearly for every target. It now builds a hash index
over the join keys once (`ReferenceIndex`) and still re-verifies every candidate with a structural
comparison, so a hash collision can only cost speed. Multi-valued keys fall back to an exact scan.
([#57](https://github.com/SQUORA-NL/TLio/pull/57))

### `resolve` can rename by lookup
A `targetPath` written as a function expression (`"=fetch(@.to)"`) computes the property name from
the matched entry, so one `resolve` can remap many properties from a table of `{from, to}` pairs.
Expressions in function arguments here used to be treated as literal text instead of resolved
paths; that is fixed. A dynamic name needs exactly one match and an object target. Relative `@.`
paths now resolve against the current node everywhere (`RelativePathResolution`).
([#57](https://github.com/SQUORA-NL/TLio/pull/57), [#58](https://github.com/SQUORA-NL/TLio/pull/58))

### Quadratic array-position lookup removed
`JToken.Path` and `JsonNode.GetPath()` re-counted an element's index from the start of its parent
array on every call. Both JSON path fetchers now keep a structural index cache, invalidated only
when the array's count changes: about 17× faster at 20,000 elements on Newtonsoft and 75× on
System.Text.Json. ([#57](https://github.com/SQUORA-NL/TLio/pull/57))

### Compiled multi-format scripts
A script that crosses a `convert` boundary had no compiled form and was re-parsed on every run.
`MultiFormatScriptRunner.Compile()` returns a `CompiledMultiFormatScript` (section executors opt in
through `ICompilableFormatSectionExecutor`). On the AFD conversion demo, per-request latency fell
from about 220 ms to 15–70 ms. ([#57](https://github.com/SQUORA-NL/TLio/pull/57))

### Documentation sweep
Every function and command page gained a *Verified example* taken from a passing fixture, and
rereading each page against its source turned up real drift that is now fixed: `minDate`/`maxDate`/
`avgDate` are variadic; `contains`, `startsWith`, `endsWith` and `indexOf` are case-insensitive;
`isEmpty` treats whitespace as not empty and fails on a missing path; `length` of an array is its
element count; `add` and `put` build missing parents; `calculate` division by zero succeeds. The AI
reference tables were missing `rename`, `convert`, `convertValue` and 36 functions. A performance
guide was added. ([#59](https://github.com/SQUORA-NL/TLio/pull/59))

## Samples

`TLio.Sample.AfdApi` — a self-contained API that converts SIVI AFD messages between AFD 1.0, AFD Short and
AFD 2.0 on this repository's own engine — was added in this release and moved to
[TLio-Samples](https://github.com/SQUORA-NL/TLio-Samples) in 1.1.0.

## Fixed
- `decisionTable` evaluated a result's value after creating its path, so a failing value provider
  left a half-written path. It evaluates first now. ([#57](https://github.com/SQUORA-NL/TLio/pull/57))

## Upgrade notes

No breaking changes. Dynamic `targetPath` expressions are new; existing literal `targetPath`
values behave as before.
