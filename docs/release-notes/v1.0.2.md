## Highlights

### `decisionTable` `outputPathTemplate`
An output may leave its own `path` empty and fall back to a shared template in which `{name}` is
substituted, instead of every declared output repeating the same path text. Applied to the three
AFD conversion scripts, it cut their combined size from 22.02 MB to 19.35 MB.

### Applying results no longer walks every declared output
`ApplyResults` looked a matched rule's result up by scanning the whole `Outputs` list — sometimes
tens of thousands of entries — for each rule application. It uses a cached outputs-by-name index,
so the cost follows the number of matched results instead of the number of declared outputs.

### Smaller tables from existing features
The `<parentEntity>Ref` relation rules in the AFD 1.0 and AFD Short → AFD 2.0 scripts were collapsed
from one rule per (entity code, parent type) pair into one per parent type, using `decisionTable`'s
array-membership condition: 3,770 rules became 375 per table, with the same firing conditions and
outputs.

([#60](https://github.com/SQUORA-NL/TLio/pull/60))
